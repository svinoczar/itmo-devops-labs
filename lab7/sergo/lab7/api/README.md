# containerization-and-orchestration-lab8-mok
Мок репозиторий для лабораторной 8 по курсу ИТМО "Контейнеризация и оркестрация"

## Transaction Service (Mock)

Микросервис для обработки транзакций и синхронизации биллинга. Данный репозиторий содержит моковую реализацию API, которая в настоящее время используется для тестирования CI/CD конвейеров и отладки AI-агентов по анализу логов (MCP).

## API Эндпоинты

### 1. Статус транзакции

**URL:** /api/v1/transactions/status

**Метод:** GET

**Описание:** Возвращает статус обработки транзакции.

### 2. Синхронизация биллинга (Webhook)

**URL:** /internal/webhook/billing-sync

**Метод:** POST

**Описание:** Внутренний вебхук для синхронизации данных с биллинговой системой. Ожидает статус 201 Created.

### 3. Маршрутизация платежа

**URL:** /api/v1/transactions/route

**Метод:** POST / GET

**Описание:** Определяет оптимальный шлюз для проведения платежа.
